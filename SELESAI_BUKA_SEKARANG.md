## ⏳ Untuk Mengaktifkan Sistem Asli (Bukan Demo)

Jika ingin mengaktifkan sistem cache yang sesungguhnya (bukan demo), butuh:

1. **Install Redis:**
   ```bash
   docker run -d -p 6379:6379 redis:latest
   ```
   Atau: `redis-server`

2. **Install Python Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Jalankan 3 Terminal:**
   ```bash
   Terminal 1: redis-server
   Terminal 2: python main.py
   Terminal 3: php -S localhost:8002 -t public
   ```

4. **Akses Dashboard:**
   ```
   http://localhost:8002/cache-monitor.html
   ```

**Lihat:** REDIS_CACHE_GUIDE.md atau MULAI_SISTEM_REDIS.md
