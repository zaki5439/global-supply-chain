================================================================================
                        TROUBLESHOOTING
================================================================================

Problem: KPI cards tidak muncul
Solution: 
  - Cache masalah → Clear dengan Ctrl+Shift+Delete
  - Use different URL: dashboard-new.html
  - Try incognito mode

Problem: Angka tidak update
Solution:
  - Refresh page: F5
  - Check DevTools console (F12)
  - Restart server

Problem: Map tidak muncul
Solution:
  - Wait 2 seconds for map to load
  - Check internet (Leaflet + OpenStreetMap CDN)
  - Try different browser

Problem: Live time tidak update
Solution:
  - Refresh page
  - JavaScript harus enabled
  - Check DevTools console
