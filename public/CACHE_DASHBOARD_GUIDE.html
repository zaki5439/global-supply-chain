🚀 Panduan Aktivasi Redis Caching Layer

Ikuti langkah-langkah di bawah untuk mengaktifkan sistem cache Redis dan melihat perubahan performa.

📋 Prasyarat

⚠️ Sebelum memulai, pastikan sudah ada:
  • Redis server installed & running
  • Python 3.8+ dengan dependencies dari requirements.txt
  • PHP 7.4+ untuk frontend

1Verifikasi Redis Running

Buka Command Prompt dan pastikan Redis sudah berjalan:

redis-cli ping

Output yang diharapkan: PONG

✅ Jika melihat PONG, Redis sudah siap!
❌ Jika error, jalankan: redis-server atau buka Docker

2Jalankan Backend FastAPI dengan Cache

Buka terminal baru dan jalankan:

cd c:\Users\ACER\supply-chain-app python main.py

Tanda-tanda berhasil:

  • ✅ "Uvicorn running on http://0.0.0.0:8000"
  • ✅ "✓ Redis connection established"
  • ✅ "✓ Cache system initialized"

3Jalankan Frontend PHP

Buka terminal ketiga dan jalankan:

cd c:\Users\ACER\supply-chain-app php -S localhost:8002 -t public

Output yang diharapkan: Listening on http://127.0.0.1:8002

🧪 Test Cache Manual

Test 1: Cek Cache Stats

Jalankan di PowerShell:

curl http://localhost:8000/api/cache/stats

Akan menampilkan statistik cache real-time seperti hits, misses, memory usage, dll.

Test 2: Fetch Data (First Time - MISS)

curl http://localhost:8000/api/country/Germany

⏱️ Waktu: ~342ms (dari API, kemudian disimpan ke cache)

Test 3: Fetch Data Lagi (CACHE HIT!)

curl http://localhost:8000/api/country/Germany

⏱️ Waktu: ~2ms (dari Redis cache) 🚀

Test 4: Clear Cache Pattern

curl -X POST http://localhost:8000/api/cache/clear?pattern=country:*

Menghapus semua cache yang cocok dengan pattern "country:*"

📊 Fitur Cache Monitor Dashboard

Di http://localhost:8002/cache-monitor.html, Anda bisa melihat:

  • ✅ Cache Hit Rate: Persentase cache yang berhasil (target > 70%)
  • ✅ Total Requests: Jumlah total request yang diproses
  • ✅ Memory Used: Memory yang digunakan Redis
  • ✅ Real-time Charts: Visualisasi hits vs misses
  • ✅ Redis Info: Status dan informasi server Redis
  • ✅ Control Buttons: Clear cache, auto-refresh

🐛 Troubleshooting

Masalah: "Redis connection refused"

Solusi:
redis-cli ping
Jika error, start Redis:
redis-server
Atau dengan Docker:
docker run -d -p 6379:6379 redis:latest

Masalah: "Module not found: redis"

Solusi:
pip install -r requirements.txt
Atau khusus redis:
pip install redis==5.0.1

Masalah: "Port 8000 already in use"

Solusi:
netstat -ano | findstr :8000 taskkill /PID [PID] /F
Atau ubah port di main.py: port=8001
