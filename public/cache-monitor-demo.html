📌 Langkah Selanjutnya

Untuk mengaktifkan sistem asli (bukan demo):

  1. Install Redis: docker run -d -p 6379:6379 redis:latest
  2. Install Python: pip install -r requirements.txt
  3. Jalankan 3 terminal:
    • Terminal 1: redis-server
    • Terminal 2: python main.py
    • Terminal 3: php -S localhost:8002 -t public
  4. Akses: http://localhost:8002/cache-monitor.html
